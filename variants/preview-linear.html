Hermes Sidekick — вариант «Linear»

Витрина пяти поверхностей на моках: чат с карточкой задачи, журнал уведомлений и меню, карточка пермиса, композер, страница настроек. Тёмная тема по умолчанию, светлая. CSS: theme.css + sidebar.css + options.css + linear.css.

Чат с шагами задачи

Карточка задачи раскрывается в ленте; шаги — статус-глифы SVG, время моноширинное; активный шаг — плоская синяя подложка, без градиентного «прожектора».

Карточка пермиса

Блокирующее решение по-Linear: нейтральная поверхность + цветной корешок-статус слева (3px, сплошной) + одна насыщенная кнопка. «Всегда разрешить» — вторичная графитовая, «Отклонить» — привидение с красной рамкой. Баннер «нужен ты» — та же семья с синим корешком.

Правила карточки
  • Один насыщенный CTA на решение — два рядом не ставятся.
  • Корешок: жёлтый = нужно решение, синий = нужен человек; нейтральный = решено.
  • Вспышка bell_focus — пульс рамки, не янтарное гало.
  • Разрешённая карточка остаётся читаемой: без opacity-затемнения.

Композер

Сплошная полоса без блюра; поле — surface-2, фокус-кольцо бренда; отправка — акцентный глиф без плашки (заливка бренда живёт в текстовых CTA), морф send/stop 150 мс без пружины, running — красный глиф.

Что делает этот вариант «линейным»
  • Лестница поверхностей тоном, hairline и inset-кромка вместо стекла и теней.
  • Бренд #5E6AD2 только на CTA/фокусе/выделении/ссылках/логотипе.
  • Радиусы 6/8/99; типографика Inter-first ≤16px, веса ≤600.
  • Ноль градиентов, ноль backdrop-filter, ноль цветных теней (счёт сканера).
  • Движение — у клавиатуры: кольцо фокуса идёт по списку; ховер — только яркость.
