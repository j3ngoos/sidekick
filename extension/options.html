Звонок

«Проверить звонок» выпускает живое системное уведомление со звуком — тем же путём, что колокольчик агента (валидная иконка из icons/, без data:). Звук даёт операционная система: у WebExtensions API звука нет. На macOS — Системные настройки → Уведомления → Firefox → «Позволить уведомления» и «Звуки». Всплывашка завершения задачи выходит только когда окно Firefox не в фокусе; пермиссы зовут всегда.

  • Firefox: about:preferences#privacy → Уведомления — расширение не должно быть в «Блокировать».
  • macOS: Системные настройки → Уведомления → Firefox → «Позволить уведомления».
  • macOS: там же включить «Звуки» — звук даёт macOS, у расширения его нет.
  • Ничего не видишь при фокусе окна — так и задумано для задач: бейдж-колокольчик и журнал. «Проверить звонок» вызывает всплывашку принудительно.

Сервер

…

WS-адрес моста Hermes. Пусто = ws://127.0.0.1:8791 — режим ssh-туннеля, как раньше. Чтобы подключиться без ssh по локальной сети, укажи адрес машины с мостом, например ws://host-a.local:8791; на мосту при этом должен стоять SIDEKICK_BIND=0.0.0.0 (systemd-юнит моста). Если указанный адрес недоступен, расширение само откатится на localhost (туннель), а ретраи пойдут экспоненциалом от 2 до 60 секунд.

ws:// передаёт токен по сети открытым текстом — только доверенная домашняя сеть; для всего остального оставь туннель (пустое поле).
